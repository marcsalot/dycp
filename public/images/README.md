# Images Directory

Place the following downloaded Adobe Stock images in this folder.
**Save each file with exactly the filename listed below** (JPEG format, no spaces).

The site works without images (falls back to a dark navy background),
but each image will dramatically improve the corresponding section.

---

## Required Images

| Filename | Used On | Adobe Stock # | Description |
|---|---|---|---|
| `hero.jpg` | Home page hero | #430896876 | Little girl playing cello, close-up warm light |
| `about-lesson.jpg` | Home About section + About page | #1168877161 | Music lesson with young cellist, classroom |
| `programs-lessons.jpg` | Programs card + Programs page | #1087720879 | Young Latina musician practicing cello |
| `programs-instruments.jpg` | Programs card | *(use #1087720879 or similar)* | Cello lesson, instrument focus |
| `programs-ensemble.jpg` | Programs card + News hero | #327148838 | Row of children playing string instruments |
| `programs-performance.jpg` | Programs card + About Future Plans | #591409743 | Cinematic cellist on theatre stage |
| `donate-atmospheric.jpg` | Stats section + Donate page hero | #1099197001 | Cello close-up, dark backlit studio |

## Recommended Sizes

- **Hero** (`hero.jpg`): Landscape, 1920×1080px or larger
- **Section images**: Landscape, 1200×800px minimum
- **Avoid images with embedded text** — it will clash with the site's overlay text

## Upload Folder

Images uploaded through the CMS admin at `/admin/` are stored in:
`public/images/uploads/`

These are committed to the repo automatically by Decap CMS.
